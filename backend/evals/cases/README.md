# evals/cases

Case lists that live in code rather than in `datasets/`: `golden.py` (the golden hundred, `--suite golden`),
`bot_golden.py` and `skill_golden.py` (the cases a published bot or skill ships with), and `lead_parity.py`
(the Lead's parity book, offline: `python -m evals.cases.lead_parity`). See `../README.md`.
